Starter food imagery in the public site uses curated remote image URLs for design preview. Before production, replace illustrative stock imagery with original or appropriately licensed Four Flavours photographs. Use Admin > Website & branding to upload the logo, browser icon/favicon, hero and story images directly. Use Cuisine cards to upload cuisine photographs, or Images & media for gallery images. Upload controls send assets to Supabase Storage and apply them through the live database.

The bundled four-flavours-logo.png is the transparent default lockup extracted from the supplied Four Flavours header reference. The public header uses this complete logo by default, without separate heading/tagline text. Administrators can replace it through Admin → Website & branding.
